LOCAL ACADEMIC PORTFOLIO — QUICK START

1) Extract this folder.
2) Keep your profile image at: assets/portfolio_profile.jpg
   (Create an assets folder if it is not already present.)
3) Open index.html in a browser. For a more reliable local preview, open a terminal in this folder and run:
       py -m http.server 8000
   Then visit http://localhost:8000
4) Search index.html for [bracketed placeholders] and replace them with your own content.
5) Project image placeholders currently refer to:
   assets/project-ug-thesis.jpg
   assets/project-pg-thesis.jpg
   assets/project-bandgap-1.jpg
   assets/project-bandgap-2.jpg
   assets/project-hydroxyapatite.jpg
   Add your own images with those filenames or change the src paths.
6) Replace [GOOGLE_DRIVE_OR_DOCS_URL], [GOOGLE_DRIVE_URL], [GITHUB_REPOSITORY_URL], etc. with actual URLs.
   Set Drive documents to appropriate viewer permissions before sharing.
7) Do not add unverified results, claims, or collaborator work without permission.
